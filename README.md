### ☁️ Azure Tools I've Worked With

I’ve spent a significant amount of time architecting, deploying, and securing systems within Microsoft Azure, deployed by hand and with [Terraform](https://developer.hashicorp.com/terraform)

- 🔐 **Azure Key Vault** – Securely manage application secrets, certificates, and encryption keys  
- 👥 **Managed Identity** – Seamlessly access Azure services without storing credentials in code  
- 🛠️ **Azure DevOps** – CI/CD pipelines, repo hosting, and infrastructure automation  
- ☸️ **Azure Kubernetes Service (AKS)** – Deploy and manage containerized applications using Kubernetes at scale  
- 📦 **Azure Container Registry (ACR)** – Private Docker container registry for image hosting  
- 🚀 **Azure App Service** – Host web apps and APIs with built-in scaling and integration  
- ☁️ **Azure Functions** – Serverless compute for event-driven microservices  
- 🛠️ **Azure API Management** – Publish, secure, transform, and monitor APIs with built-in policies and developer portal  
- 💾 **Azure SQL Server** – Scalable, managed relational database with built-in high availability and security  
- 📦 **Azure Storage Account** – Object/blob storage for scalable data access across applications  
- 🧩 **SFTP on Azure** – Secure file transfer integrated with blob storage and identity control  
- 🔄 **Azure Data Factory** – Orchestrate and automate data movement and transformation at scale  
- 🧠 **Azure Application Insights** – Real-time telemetry, diagnostics, and performance monitoring  
- 📊 **Azure Monitor & Log Analytics** – Centralized log and performance data collection with Kusto queries  
- 🚪 **Azure Front Door** – Global load balancer and application accelerator (Classic version also... 😞)  
- 🌍 **Azure CDN** – Globally deliver content with low latency and high performance via content delivery networks
